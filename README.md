# 역사 쇼츠 프롬프트 입력 앱

한국 역사 인물 AI 셀피 브이로그 프롬프트를 입력값 기반으로 생성하는 정적 웹앱입니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 업로드합니다.
   - `index.html`
   - `Korean Historical Selfie VLOG Script & Prompt Generator v1.0.txt`
   - `.nojekyll`
3. 저장소의 `Settings`로 이동합니다.
4. `Pages` 메뉴를 엽니다.
5. `Build and deployment`에서 다음처럼 선택합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. 저장하면 잠시 후 공개 링크가 생성됩니다.

## 공개 링크 형식

```text
https://깃허브아이디.github.io/저장소이름/
```

예:

```text
https://yourname.github.io/history-shorts-prompt-app/
```
